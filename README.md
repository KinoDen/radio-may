# Радио Май — мини-приложение для MAX

Международное радио в виде кассетной деки в стиле Winamp: анимированная кассета, эквалайзер, жанровый каталог, поиск станций, погода по городам, часы. Тёмная и светлая темы.

## Файлы
- `index.html` — разметка (подключает MAX Bridge: `https://st.max.ru/js/max-web-app.js`)
- `style.css`, `app.css` — оформление
- `app.js` — вся логика (без сборки и зависимостей)

## Запуск локально
```
cd radio-may
python3 -m http.server 8080
```
Открыть http://localhost:8080 в браузере.

## Публикация в MAX
1. Выложите все файлы на HTTPS-хостинг (GitHub Pages, VK Cloud, Yandex Cloud). Ссылка должна быть только `https://`, без пробелов и спецсимволов.
2. Платформа MAX для партнёров → Чат-боты → ваш бот → ⋮ → Настройки.
3. Вставьте ссылку на приложение в поле мини-приложения, выберите вид кнопки запуска, сохраните.
4. Мини-приложение открывается внутри чат-бота.

Подробнее: https://dev.max.ru/docs/webapps/introduction

## Откуда данные (ключи не нужны)
- Станции: российский каталог полностью плюс выбранные позиции топ-списков Великобритании и США (GB: 6, 10, 12, 14, 26, 39, 52; US: 3, 5, 9, 10, 12, 16, 17, 36, 43, 60, 61, 64, 67). Запросы сортируются по `clickcount`, `hidebroken=true`; берутся только `https`-потоки без HLS. Каталог разбивается по жанрам на основании тегов и названий станций.
- Погода: wttr.in → MET Norway → Open-Meteo (автоматическое переключение при сбое); последний успешный результат кэшируется на устройстве.
- Поиск городов: Open-Meteo Geocoding с резервным геокодером Photon.
- Названия стран: встроенный `Intl.DisplayNames`.

## Важно знать
- Доступность внешних API и отдельных радиопотоков зависит от сети и решений операторов. Погодные источники опрашиваются по очереди; окончательную проверку нужно выполнить из российской сети без VPN.
- **Эквалайзер.** Если сервер станции отдаёт CORS-заголовки, спектр строится по реальному звуку (в дисплее «FFT»). Если нет, звук играет нормально, а спектр имитируется (в дисплее «SIM»). Это ограничение браузера, обойти его можно только своим прокси-сервером для потоков.
- Станции с `http://`-потоками скрыты: в `https`-приложении браузер их блокирует.
- Звук начинается только после нажатия PLAY (правило браузеров и мессенджеров).
- На iOS громкость потока без CORS регулируется кнопками устройства.
- Тема, громкость, последняя станция, выбранный жанр в текущем сеансе и список городов запоминаются/обрабатываются на устройстве.

- **Фоновое воспроизведение.** Поток воспроизводится напрямую через HTMLAudioElement без WebAudio-графа, чтобы снизить риск приостановки звука при сворачивании WebView. Однако MAX может приостанавливать само мини-приложение в фоне; гарантированное воспроизведение при закрытии/сворачивании MAX требует Android Foreground Service в нативном Android-проекте. В этом архиве такого Android-кода нет.
- **Шторка и Bluetooth.** Через Media Session API: в шторке уведомлений и на магнитоле работают play/pause/stop и «следующая/предыдущая станция». Кнопки (и экранные «◀◀ ▶▶») переключают станции в том же списке: если станция запущена из вкладки «Избранное» — только избранное, иначе весь список страны. Работает, пока приложение открыто в браузере/WebView с поддержкой Media Session (Chrome, Safari); внутри MAX зависит от самого клиента MAX.
