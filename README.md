# Радио Май — мини-приложение для MAX

Международное радио в виде кассетной деки в стиле Winamp: анимированная кассета, спектр, страны, поиск станций, погода по городам, часы. Тёмная и светлая темы.

## Файлы
- `index.html` — разметка (подключает MAX Bridge: `https://st.max.ru/js/max-web-app.js`)
- `style.css`, `app.css` — оформление
- `app.js` — вся логика (без сборки и зависимостей)

## Запуск локально
```
cd radio-may
python3 -m http.server 8080
```
Открыть http://localhost:8080 в браузере.

## Публикация в MAX
1. Выложите все файлы на HTTPS-хостинг (GitHub Pages, VK Cloud, Yandex Cloud). Ссылка должна быть только `https://`, без пробелов и спецсимволов.
2. Платформа MAX для партнёров → Чат-боты → ваш бот → ⋮ → Настройки.
3. Вставьте ссылку на приложение в поле мини-приложения, выберите вид кнопки запуска, сохраните.
4. Мини-приложение открывается внутри чат-бота.

Подробнее: https://dev.max.ru/docs/webapps/introduction

## Откуда данные (ключи не нужны)
- Станции: каталог Radio Browser (radio-browser.info). Берутся только `https`-потоки без HLS.
- Погода и время города: Open-Meteo.
- Названия стран: встроенный `Intl.DisplayNames`.

## Важно знать
- **Эквалайзер.** Если сервер станции отдаёт CORS-заголовки, спектр строится по реальному звуку (в дисплее «FFT»). Если нет, звук играет нормально, а спектр имитируется (в дисплее «SIM»). Это ограничение браузера, обойти его можно только своим прокси-сервером для потоков.
- Станции с `http://`-потоками скрыты: в `https`-приложении браузер их блокирует.
- Звук начинается только после нажатия PLAY (правило браузеров и мессенджеров).
- На iOS громкость потока без CORS регулируется кнопками устройства.
- Тема, громкость, страна, последняя станция и список городов запоминаются на устройстве.
