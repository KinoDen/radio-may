# Радио Май — мини-приложение для MAX

Международное радио в виде кассетной деки в стиле Winamp: анимированная кассета, спектр, жанры, поиск станций, погода по городам, время воспроизведения и часы. Тёмная и светлая темы.

## Файлы
- `index.html` — разметка (подключает MAX Bridge: `https://st.max.ru/js/max-web-app.js`)
- `style.css`, `app.css` — оформление
- `genres.js` — список жанров и классификация станций
- `app.js` — вся логика (без сборки и зависимостей)
- `catalog.json` — (необязательно) проверенный снимок зарубежных станций, см. ниже
- `tools/build_catalog.mjs` — сборка и проверка зарубежной части каталога; `tests/` — автотесты
- `ANDROID.md` — что нужно для фонового воспроизведения в Android APK; `CHANGES.md`, `reports/` — отчёты

## Запуск локально
```
cd radio-may
python3 -m http.server 8080
```
Открыть http://localhost:8080 в браузере.

## Публикация в MAX
1. Выложите все файлы на HTTPS-хостинг (GitHub Pages, VK Cloud, Yandex Cloud). Ссылка должна быть только `https://`, без пробелов и спецсимволов.
2. Платформа MAX для партнёров → Чат-боты → ваш бот → ⋮ → Настройки.
3. Вставьте ссылку на приложение в поле мини-приложения, выберите вид кнопки запуска, сохраните.
4. Мини-приложение открывается внутри чат-бота.

Подробнее: https://dev.max.ru/docs/webapps/introduction

## Откуда данные (ключи не нужны)
- Станции: сначала российское зеркало каталога, затем резервные узлы Radio Browser. Берутся только `https`-потоки без HLS. В каталог входят все станции России, 7 станций Великобритании и 13 станций США (отбор по порядковым номерам исходного списка по популярности — см. `CHANGES.md`); остальные страны исключены.
- Зарубежные станции: если рядом с `index.html` лежит `catalog.json` (его создаёт `node tools/build_catalog.mjs` после проверки потоков), берутся станции из него. Если файла нет — выбор по тем же номерам делается живым запросом и фиксируется на устройстве.
- Погода: wttr.in → MET Norway → Open-Meteo (автоматическое переключение при сбое); последний успешный результат кэшируется на устройстве.
- Поиск городов: Open-Meteo Geocoding с резервным геокодером Photon.
- Названия стран (в информационном окошке): встроенный `Intl.DisplayNames`.

## Важно знать
- Доступность внешних API и отдельных радиопотоков зависит от сети и решений операторов. Погодные источники опрашиваются по очереди; окончательную проверку нужно выполнить из российской сети без VPN.
- **Эквалайзер.** Если сервер станции отдаёт CORS-заголовки, спектр строится по реальному звуку (в дисплее «FFT»). Если нет, звук играет нормально, а спектр имитируется (в дисплее «SIM»). Это ограничение браузера, обойти его можно только своим прокси-сервером для потоков.
- Станции с `http://`-потоками скрыты: в `https`-приложении браузер их блокирует.
- Звук начинается только после нажатия PLAY (правило браузеров и мессенджеров).
- На iOS громкость потока без CORS регулируется кнопками устройства.
- Тема, громкость, жанр, последняя станция, избранное и список городов запоминаются на устройстве.
- **Жанры.** Блок со стрелками переключает жанры по кругу: ВСЕ → РОК → ПОП → ДЖАЗ → НОВОСТИ → ЭЛЕКТРОННАЯ МУЗЫКА → РЕТРО → КЛАССИКА → (ШАНСОН, ХИП-ХОП, ДЕТСКОЕ — если в каталоге есть такие станции) → ДРУГИЕ. Жанр определяется по тегам каталога и формату вещания; нет признаков — «ДРУГИЕ». Станция с несколькими жанрами видна в каждом. Смена жанра не останавливает и не меняет текущую станцию; поиск и избранное работают внутри каталога.
- **Часы и время воспроизведения.** Верхний зелёный дисплей — местное время устройства (ЧЧ:ММ). Нижний правый блок — время воспроизведения текущей станции (Ч:ММ и секунды), считается по меткам времени, на паузе не идёт.

- **Шторка и Bluetooth.** Через Media Session API: в шторке уведомлений и на магнитоле работают play/pause/stop и «следующая/предыдущая станция». Кнопки (и экранные «◀◀ ▶▶») переключают станции в том же списке: если станция запущена из вкладки «Избранное» — только избранное, иначе список выбранного жанра. Работает, пока приложение открыто в браузере/WebView с поддержкой Media Session (Chrome, Safari); внутри MAX зависит от самого клиента MAX.
