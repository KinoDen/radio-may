## 1. Жанры вместо стран
Блок со стрелками и окном остался на месте (разметка, размеры, стили не тронуты). Подпись «СТРАНА» → «ЖАНР».
Стрелки листают жанры по кругу; нажатие на окно открывает список жанров с количеством станций.
Длинное «ЭЛЕКТРОННАЯ МУЗЫКА» не помещается в окно и бегущей строкой прокручивается тем же приёмом, что строки погоды.
Жанры: ВСЕ, РОК, ПОП, ДЖАЗ, НОВОСТИ, ЭЛЕКТРОННАЯ МУЗЫКА, РЕТРО, КЛАССИКА + найденные в каталоге **ШАНСОН, ХИП-ХОП, ДЕТСКОЕ** + ДРУГИЕ (всегда последний).
Жанр, в котором нет ни одной станции, в цикле пропускается.

## 2. Состав каталога
* **Россия** — без изменений и без отсева: прежний запрос (до 120 станций каталога) + 20 встроенных потоков.
* **Великобритания** — позиции 6, 10, 12, 14, 26, 39, 52; **США** — 3, 5, 9, 10, 12, 16, 17, 36, 43, 60, 61, 64, 67 исходного списка по популярности.

## 3. Жанровая классификация
Жанры — только по явным признакам: теги каталога, формат в названии, небольшой список известных новостных/классических станций; иначе «ДРУГИЕ».
Для 20 встроенных потоков жанры заданы вручную (см. `reports/genres_featured.md`). Станция может входить в несколько жанров.
Переключение жанра меняет только список: текущая станция, воспроизведение, громкость, поиск, избранное не трогаются; случайная станция не запускается.
«Предыдущая/следующая» ходят по списку выбранного жанра (из избранного — по избранному, как и раньше).

## 4. Часы и время воспроизведения
Верхний зелёный дисплей — местное время устройства (ЧЧ:ММ). Нижний правый блок — время воспроизведения (Ч:ММ + секунды).
Шрифты, размеры, подсветка, выравнивание и мигающее двоеточие — прежние. Время воспроизведения считается по меткам времени (не по счётчику), поэтому не «плывёт» при троттлинге в фоне; на паузе стоит, при STOP/смене станции обнуляется.
Раньше нижний блок мог показывать время выбранного города погоды — теперь это всегда время устройства (только в верхнем дисплее).

## 5. Остановка музыки при сворачивании
Что проверено в коде: аудиоэлемент не уничтожается при перерисовке (`render()` только обновляет текст), при открытии списков и смене темы он не пересоздаётся, одновременно живёт один элемент.
Найденные причины и исправления:
1. Звук идёт через Web Audio (ради живого спектра). ОС приостанавливает Web Audio при сворачивании/блокировке — звук замолкает, хотя `<audio>` «играет». Теперь при `visibilitychange: hidden` / `pagehide` / приостановке `AudioContext` поток переводится на обычный `<audio>` (один элемент; спектр временно имитируется).
2. Любая сетевая ошибка/конец «живого» потока в фоне вызывали `fail()` и навсегда останавливали плеер. Теперь — автопереподключение (до 5 раз для работавшего потока, 2 — для не заигравшего).
3. Добавлена обработка возврата (`visibilitychange: visible`, `pageshow`): если система поставила звук на паузу или элемент потерян — воспроизведение продолжается; Wake Lock запрашивается заново. Внешняя пауза (гарнитура, звонок) отражается на панели.
Ограничение: если клиент MAX сам замораживает WebView — веб-код этого не обойти; для APK нужен нативный сервис, см. `ANDROID.md`.
