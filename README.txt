РАДИО МАЙ — интерфейс по присланному MAX RADIO скриншоту

Сохранена компоновка референса:
- вертикальная компоновка узкой панели;
- чёрные дисплеи и фиолетово-серый корпус;
- зелёные цифровые надписи;
- L/R светодиодные шкалы и спектроанализатор;
- отдельные панели погоды и плейлиста;
- компактные кнопки управления;
- без стрелочных VU-метров.

Открой index.html в браузере.

ВАЖНО: в исходном каталоге у большинства станций stream пустой, поэтому звук не появится,
пока не добавим проверенные прямые URL потоков. Значки станций загружаются по favicon доменов;
для идеальных фирменных логотипов лучше добавить отдельные файлы логотипов.
Погода сейчас демонстрационная, без внешнего API.
