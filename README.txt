РАДИО МАЙ — версия 0.8

Новый порядок плеера:
1. Кассета с анимированными катушками.
2. Два аналоговых VU-метра.
3. 48-полосный Winamp-спектровизуализатор.
4. Название и статус радиостанции.
5. Кнопки управления в стиле портативного Walkman.

Дополнительно:
- Локальные часы используют время устройства.
- Погода загружается через Open-Meteo без API-ключа.
- Город погоды по умолчанию: Воронеж; его можно изменить нажатием на погодный блок.
- Визуализаторы анимируются во время эфира. Точный анализ частот зависит от CORS-заголовков потока радиостанции; если сервер их не отдаёт, работает визуальный режим.
- Логотипы подгружаются с официальных сайтов вещателей или с опубликованных страниц логотипов. При недоступности внешнего изображения используется текстовый знак.
- Вращаются внутренние катушки; корпус и рамка кассеты остаются неподвижными.
