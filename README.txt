РАДИО МАЙ — версия 1.2 STUDIO

Состав архива:
- index.html — новый интерфейс в стиле ретро Hi-Fi / AIMP-inspired без логотипа AIMP;
- stations.json — каталог радиостанций (дубликат каталога для справки и дальнейшего редактирования).

Что добавлено:
- основная тёмная тема и светлая тема сатинового алюминия, переключатель сохраняет выбор;
- компактная студийная компоновка: обложка текущей станции, спектроанализатор, аналоговые VU-индикаторы, декоративные лампы, визуальный эквалайзер и металлические кнопки;
- фильтры по странам: Россия первой, Великобритания, США, Германия, Франция, Швейцария и все страны;
- поиск, избранное, недавние станции;
- 34 станции, включая российские, британские, американские и европейские;
- логотипы загружаются как favicon сайтов радиостанций; если сайт не отдаёт значок, автоматически показывается текстовый знак;
- часы и погода (Open-Meteo, город можно изменить нажатием на погодный блок);
- резервные адреса Pioneer FM и Нашего Радио.

УСТАНОВКА:
1. Распаковать ZIP.
2. В GitHub открыть репозиторий KinoDen/radio-may.
3. Add file → Upload files.
4. Загрузить index.html и stations.json, заменив прежний index.html.
5. Commit changes.
6. Дождаться зелёного github-pages deployment и открыть https://kinoden.github.io/radio-may/

ВАЖНО:
- Адреса интернет-потоков могут меняться и некоторые вещатели ограничивают воспроизведение по регионам или встраивание в браузер.
- Pioneer FM использует опубликованный прямой адрес и резервные URL. Если они не работают у конкретного провайдера, потребуется другой официальный поток.
- Логотипы берутся из favicon доменов станций. Для некоторых станций favicon может быть упрощённым значком, а не фирменным большим логотипом.
- Спектр, стрелки VU и лампы — анимированные визуальные индикаторы. Точный анализ звука из внешнего радио-потока браузер может блокировать из-за CORS; поэтому они не заявлены как точный измерительный прибор.
- Эквалайзер показан как визуальный элемент панели, не меняет звук потока.
