РАДИО МАЙ — версия 1.5 / Reference Design

Это сборка по утверждённому пользователем макету:
- тёмная тема: шлифованный чёрный металл, хром, янтарная подсветка;
- светлая тема: сатинированный серебристый алюминий;
- единая компоновка в обеих темах;
- слева логотип станции, название и описание;
- ниже два аналоговых VU-метра и 48-полосный спектроанализатор;
- снизу физические кнопки управления и громкость;
- справа библиотека станций с логотипами, вкладками и поиском;
- русские станции идут первыми, затем Великобритания, США и Европа;
- добавлены BBC Radio 1, BBC Radio 2, France Inter и Deutschlandfunk.

Публикация:
1. Распаковать архив.
2. В GitHub открыть репозиторий radio-may.
3. Add file -> Upload files.
4. Загрузить index.html и stations.json, подтвердить замену файлов через Commit changes.
5. Открыть Settings -> Pages и дождаться зелёного статуса deployment.

Примечание:
Потоки и логотипы загружаются из интернета. Доступность отдельных потоков может зависеть от региона, браузера и изменений у вещателя.
Погода загружается через Open-Meteo. Для HLS используется hls.js с CDN.
