РАДИО МАЙ — Hi-Fi Edition
Сборка с новой компоновкой по утверждённому макету.

Загрузка:
1. Заменить index.html в корне GitHub-репозитория radio-may.
2. stations.json можно оставить текущий или заменить этим файлом.
3. Commit changes и дождаться успешного GitHub Pages deployment.
4. Открыть сайт и нажать Ctrl+F5.

Функции:
- две темы: тёмный шлифованный металл и светлый анодированный алюминий;
- список станций, поиск, избранное, недавние;
- фильтр по странам;
- воспроизведение MP3/AAC и HLS через hls.js;
- аналоговые VU-индикаторы и 48-полосный спектроанализатор;
- громкость и кнопки управления в стиле портативной Hi-Fi техники.

Примечание: реальные логотипы загружаются как фавиконы доменов вещателей.
Аудиовизуализация зависит от CORS-разрешений радиопотока; при их отсутствии
используется визуальная имитация уровня, а не точный спектральный анализ.
