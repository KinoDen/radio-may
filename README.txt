РАДИО МАЙ — версия 1.3 AIMP REBUILD

Это новая сборка интерфейса по утверждённому макету: широкая Hi‑Fi панель,
металлические элементы, оранжевая подсветка, спектроанализатор, аналоговые
VU-метры, лампы, эквалайзер, список станций и переключение тёмной/светлой темы.

Файлы:
- index.html — готовое приложение (каталог встроен, отдельный JSON оставлен для редактирования);
- stations.json — редактируемый каталог из 34 станций.

Установка на GitHub Pages:
1. Распакуйте архив.
2. В репозитории KinoDen/radio-may нажмите Add file → Upload files.
3. Загрузите index.html и stations.json с заменой существующих.
4. Нажмите Commit changes.
5. Дождитесь зелёного статуса github-pages в разделе Deployments.
6. Откройте https://kinoden.github.io/radio-may/ и обновите страницу Ctrl+F5.

Важно:
- Плеер использует прямые интернет-потоки из каталога. Радиостанции могут менять URL,
  блокировать отдельные регионы или запрещать воспроизведение во встроенном браузере.
- Pioneer FM содержит резервные адреса, но доступность каждого потока нужно проверять
  из вашей сети.
- Логотипы загружаются через favicon домена вещателя; если домен не отдаёт иконку,
  показывается буквенный знак. Для стабильных брендовых логотипов позже можно положить
  изображения локально в репозиторий.
- Спектр и VU-стрелки в этой версии — визуальные анимации, не точный аудиоанализ:
  внешние потоки часто недоступны Web Audio API из-за CORS.
- Эквалайзер в этой версии декоративный; реальная обработка аудио не включена.
- Часы используют локальное время устройства. Погода загружается через Open-Meteo;
  город меняется нажатием на погодный блок или кнопку настроек.
