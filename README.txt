РАДИО МАЙ — Reference Rebuild

Эта сборка повторяет утверждённый макет: широкий Hi-Fi плеер слева, список станций справа, нижняя панель стран, верхняя панель времени/погоды и переключатель тёмной/светлой темы. Брендинг AIMP удалён.

Файлы:
- index.html — интерфейс, плеер, спектроанализатор, VU-индикаторы, эквалайзер, часы и погода.
- stations.json — каталог радиостанций (34 записи).

Публикация:
1. В GitHub открой репозиторий KinoDen/radio-may.
2. Add file → Upload files.
3. Загрузи index.html и stations.json, замени старые.
4. Commit changes.
5. После успешного GitHub Pages открой https://kinoden.github.io/radio-may/ и обнови Ctrl+F5.

Примечание: спектроанализатор и VU-индикаторы в этой версии являются визуальной анимацией, не реальным Web Audio-анализом. Логотипы загружаются по favicon доменов вещателей и могут различаться по качеству/доступности.
