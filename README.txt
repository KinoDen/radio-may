# Радио Май

Адаптивный веб-плеер на чистом HTML/CSS/JavaScript.

## Запуск локально
Откройте `index.html` в современном браузере. Для корректной работы некоторых потоков и погодного виджета рекомендуется запускать через HTTPS (например, GitHub Pages).

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите `index.html` в корень репозитория `radio-may`.
3. Если GitHub спросит о замене файла — подтвердите.
4. Откройте Settings → Pages и проверьте `Deploy from a branch`, ветка `main`, папка `/(root)`.
5. Дождитесь зелёного статуса Deployments и откройте `https://kinoden.github.io/radio-may/`.

## Важно о потоках и логотипах
- В каталог внесены станции России, Великобритании, США и Европы.
- Для части станций прямые URL потоков не добавлены: вещатели меняют адреса, используют геоблокировку или требуют официального плеера. Такие станции отображаются в каталоге, но кнопка воспроизведения честно сообщает, что прямой поток пока не подключён.
- Логотипы загружаются как favicon сайтов вещателей; если favicon недоступен, показывается цветной буквенный знак. Это не всегда фирменный логотип станции.
- Радиопотоки могут не работать в отдельных странах или браузерах; это зависит от вещателя, а не от интерфейса.
- Спектроанализатор и стрелки VU здесь анимированы как визуальный индикатор. Это не калиброванный анализ аудиосигнала.
- Эквалайзерные ползунки пока являются интерфейсными настройками и не обрабатывают звук DSP-фильтрами.

## Реально работающие элементы
Переключение темы с сохранением, выбор стран, вкладки станций/избранного/недавних, поиск, выбор станции, play/pause/stop, предыдущая/следующая станция, громкость, раскрытие панели EQ, часы и погода по выбранному городу.
